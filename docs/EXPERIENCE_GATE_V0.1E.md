# Wish Garden — Experience Gate V0.1E
Date: 2026-11-04 · Scope: independent private-by-default static preview.

## Product invariant
Wish Garden is a symbolic, calm place for sending wishes, prayers and hopes. We do not claim the Universe receives data as a physical signal, that prayers are answered by the application, or that numbers of other participants are real before a verified backend exists.

## Implemented
- Responsive bilingual ritual and original illustrative SVG sanctuary scene
- Private-by-default release (do not save)
- Explicit optional localStorage saving, JSON export, deletion
- Basic reduced-motion setting; preference reflected in release animation and CSS
- No account, backend, payments, telemetry or real community metrics

## Limitations
- Storage in browser localStorage is NOT encrypted; browser or shared-device access can expose saved text
- This is an illustrative client-side prototype, not health treatment, a religious authority, or production-grade private journaling
- No actual community event streaming, moderation, accessibility audit, independent security audit, or real-user testing yet
- Visual design remains exploratory; upcoming testing must verify readability and rendering on real devices

## Release gates for a future public beta
1. Document threat model, consent and data-retention controls
2. Test on actual hosted URL (desktop/mobile, keyboard, reduced motion, accessibility)
3. Design opt-in sharing and moderation before public wishes
4. Implement rate limits, deletion/export, privacy policy and incident response
5. Establish real user opt-in counting semantics before Collective Hope visualization

## Future directions (NOT built)
Family Garden, Memory Home, 3D construction, creator marketplace and Life Engine remain research branches. No integration with BuiTai.
