# Wish Garden V0.2T — Free RF provider shortlist (5 November 2026)

## New leading candidate: SpaceSIO
- https://spacesio.com/explore
- https://spacesio.com/features
- **Published Ground Control free plan: 3 text signals per month, maximum 140 characters per signal.** Provider advertises a public proof page, signed station confirmation, radio packets, logs and repeat echoes.
- Public example: https://spacesio.com/t/408d23d8b851 — displays `SIOComms1`, SHA-256 payload hash, Ed25519 station signature, UTC/broadcast telemetry, claimed transmitted state.
- CRITICAL: This is **provider-issued attestation**, not independently witnessed spectrum evidence or independently audited regulatory authority. Need confirm operator, station's actual RF licence, signed record public key and verifier, proof contents, frequency, actual dates, programme restrictions, repeat schedule, and cost/contract stability.
- The free plan is offered through the website; **MCP/automated API requires a paid plan**, so do NOT call automation endpoints or scrape to submit. Use the normal free manual account UI for a first harmless project-only test.
- Privacy: transmissions may be public and permanent; use exclusively a harmless project phrase, never personal wishes or user counts without current consent.

## Other free candidates
- SpaceSpeak: https://www.spacespeak.com/Pricing — individual free text up to 2,000 chars; automated/API usage requires separate license and public pricing shows a USD 500 setup fee. Terms forbid automation without written permission: https://www.spacespeak.com/Learn/UserAgreement. Candidate for one manually submitted public project sentence, not an API.
- gateto.space: https://gateto.space — first 32-character 'SMS to Space' free, later earn energy units; beta registration access and provider attestation remain unverified.
- Spacecast: https://spacecast.univer.se/about-spacecast — claims free radio text/photo uplinks but we have not validated a current public form or verifiable station receipt.

## Decision: Pilot zero cost, no shortcuts
1. Use SpaceSIO free website if a no-payment account can be created; only project-owned test text:
   `WISH GARDEN | PEACE, FAMILY, HEALTH AND HOPE FROM EARTH`
2. Record exact submission URL/reference/timestamp and distinguish `queued` from `station-attested transmitted`.
3. Download/capture actual proof page, check its timestamp, claimed station, waveform/hash, signature and provider legal details, and — where feasible — verify independent SDR reception or station operator.
4. Do not mark Wish Garden as 'sent' or change the planned countdown into a confirmed date until a real record exists.
5. Keep normal prayers private; future batch counts need a real opt-in backend and separate, fresh user consent. The current local-only interest is NOT a globally counted batch.
6. One founder pilot at most. No payment, no user prayers, no bulk automated requests.

## Assessment
SpaceSIO currently has the clearest publicly advertised *free allowance plus provider proof fields*, and is sufficient as a candidate for twice-yearly use. That does not yet establish verified physical radiation. Pilot status: **NOT SUBMITTED / NOT VERIFIED** as of this document.
