# Wish Garden Visual Rebuild — V0.2A
Date: 2026-11-04
Status: static GitHub Pages preview, NOT production

## Product correction
Earlier work repeatedly produced moodboard images, but the live website stayed mostly text and form controls. V0.2A moves the actual product toward the agreed concept: the user should experience a peaceful place and feel present in it, rather than encounter an app form on entry.

## Implemented in GitHub Pages preview
- Immersive full-viewport sanctuary entrance.
- Illustrated visitor avatar within the scene, in a prayer posture. It is a static symbolic avatar, not yet a user-customizable 3D character.
- One main invitation button **Enter the sanctuary**. The prayer form remains hidden until the visitor chooses to begin.
- Vietnamese and English interface maintained.
- Ritual, optional local-only save, export/deletion, reduced-motion support and symbolic constellation retained.

## Visual production gaps
- The sanctuary is still an original lightweight SVG illustration; it does NOT yet match the photorealistic cinematic art reference.
- No walkable 3D environment, avatar customization, camera movement, or user-uploaded portrait.
- Do not ship reference image files as a public asset without confirming redistribution rights and license provenance.
- Consider a curated, optimized visual background and transparent layered visitor sprite as the next art implementation, followed by a performance test on mobile.

## Safety & release gates
- No wish is transmitted; storage is opt-in on the local browser and is not encrypted.
- No simulated public user count and no supernatural guarantees.
- GitHub CI checks structure, JavaScript compilation and privacy invariants; does not substitute for browser QA or accessibility audit.
- Next formal QA: smartphone viewports, avatar contrast, keyboard navigation and manual reduced motion.
