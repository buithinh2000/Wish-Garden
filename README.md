# Wish Garden — Private Preview (V0.1D)
Independent project, unrelated to BuiTai.

## Purpose
A quiet symbolic ritual for sending personal hopes, wishes, and prayers toward the sky.

## Current scope
- Responsive bilingual English/Vietnamese standalone website
- Symbolic light-release animation with reduced-motion setting
- Do not save (default), or save optionally to browser localStorage
- Export JSON and delete locally saved wishes
- No backend, analytics, social feed, payment, user accounts or collective wish counts

## Local preview
Open `index.html` in a browser.

## Deployment
This repository includes a GitHub Pages Actions workflow. Repository admin must select **Settings → Pages → Build and deployment → Source: GitHub Actions** if not already selected. The website is public when deployed; **do not enter real private sensitive wishes in a preview on a shared device**.

Expected URL after a successful Pages workflow:
https://buithinh2000.github.io/Wish-Garden/

## Safety & limitations
The ritual is artistic and offers no supernatural or therapeutic guarantees. No wish is sent to a server. Optional data stored in localStorage is not encrypted. Do not represent simulated graphics as real user activity.

## Roadmap (not included in this preview)
Privacy-first backend, verified Collective Hope counts, moderation, accessibility and security QA, and only later Family Garden / Living Memories / Life Engine.

## Release gate
Do not label this production-ready until Pages deployment is verified and browser tests on its actual origin pass.
